# Descriptive Statistics (legacy)

Descriptive statistics calculator and course for students: frequency tables, means, quartiles, variance and charts.

This repository holds the original native Android app (Java, with the course in HTML). It is archived and no longer maintained.
The app is now developed in Flutter at [netersoft/descriptive-statistics](https://github.com/netersoft/descriptive-statistics).
The new app keeps the same application id, so it ships on the [Play Store](https://play.google.com/store/apps/details?id=com.neteru.tixtat) as an update of this one.

## Project

- Application id: `com.neteru.tixtat`
- Version in this repository: 1.3.3
- Android Studio project (Gradle), `minSdkVersion` 16

The project targets the Android SDK and Gradle versions of its time and is not expected to build as is with current tools.
